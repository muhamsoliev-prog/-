## ✨ Что это?

**OSINOT** — это полнофункциональный аналитический дашборд для продавцов Wildberries, переделанный с современным дизайном, системой токенов и готовый к продакшену.

### 🎨 Дизайн
- ✅ Тёмная тема (#0D1117)
- ✅ Неоновый зелёный акцент (#00D084)
- ✅ Glow эффекты и анимации
- ✅ Inter шрифт из Google Fonts
- ✅ Полная система дизайн-токенов

### 📊 Функциональность
- ✅ 12 KPI карточек (заказы, финансы, итоги)
- ✅ Управление WB API токенами (6 типов)
- ✅ 4 тарифных плана с гибкой ценой
- ✅ Таблица товаров с фото и маржой
- ✅ Поиск, фильтры, сортировка, Excel экспорт
- ✅ Локализация (4 языка)
- ✅ Система уведомлений

### ⚡ Технология
- React 18.3.1 + TypeScript 5.4.5
- Vite 5.1.4 для быстрой разработки
- lucide-react для иконок
- framer-motion для анимаций
- react-hot-toast для уведомлений

## 🚀 Быстрый старт

### 1. Установка
```bash
# Клонировать проект
git clone <your-repo-url>
cd osinot-skeleton

# Установить зависимости
npm install
```

### 2. Разработка
```bash
# Запустить dev сервер
npm run dev

# Откроется на http://localhost:5175
```

### 3. Production
```bash
# Собрать проект
npm run build

# Preview production версии
npm run preview

# Деплой на Vercel / GitHub Pages / свой сервер
```

## 🔑 Управление WB токенами

6 типов токенов в Settings:

1. **📊 Статистика** — API для получения статистики продаж
2. **🔥 Аналитика** — Данные по спросу и трендам
3. **💵 Финансы** — Информация о выплатах и удержаниях
4. **📝 Контент** — Управление карточками товаров
5. **🏷️ Цены** — API для работы с ценами
6. **📢 Реклама** — Работа с рекламными кампаниями

Каждый токен имеет:
- ✅ Password input с toggle (показать/скрыть)
- ✅ Check button для проверки
- ✅ Status indicator (активен/ошибка/пусто)
- ✅ Время последней синхронизации

## 🎨 Цветовая система

### Основные цвета
```css
--accent: #00D084           /* Неоновый зелёный (PRIMARY) */
--bg-main: #0D1117          /* Основной фон */
--bg-card: #161B22          /* Фон карточек */
--text-primary: #E6EDF3     /* Основной текст */
--text-secondary: #8B949E   /* Вторичный текст */
```

### KPI цвета
```css
#06B6D4 → Cyan (Информация)
#00D084 → Green (Успех, прибыль)
#FF6B6B → Red (Ошибка, убыток)
#FFB830 → Orange (Внимание, реклама)
#58A6FF → Blue (Финансы, налоги)
#A8B3CF → Gray (Нейтральное)
```
