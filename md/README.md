# OSINOT - Premium SaaS Platform для Продавцов Маркетплейсов

## 📋 Описание Проекта

OSINOT - это современная премиум SaaS платформа, разработанная для владельцев магазинов на маркетплейсах (Wildberries, Ozon, Яндекс.Маркет). Платформа предоставляет аналитику продаж, управление товарами, финансовый учёт и автоматизацию бизнес-процессов.

## 🎯 Основная Задача

Решить проблемы продавцов маркетплейсов:
- ✅ Отслеживание продаж и выручки в реальном времени
- ✅ Анализ финансовых потоков (недоплаты, удержания, налоги)
- ✅ Управление товарами и инвентарём
- ✅ Расчёт себестоимости и прибыли
- ✅ Мониторинг рекламных кампаний
- ✅ Таксономия и SEO оптимизация товаров

## 🔐 Система Подписок (4 уровня)

1. **Starter** (Бесплатно)
   - Базовая аналитика
   - 1 магазин
   - Ограниченные отчёты

2. **Basic** (1,490₽/мес)
   - Полная аналитика
   - 3 магазина
   - Расширенные отчёты
   - API доступ

3. **Pro** (2,990₽/мес)
   - Неограниченные магазины
   - Приоритетная поддержка
   - Углубленная аналитика
   - Интеграции

4. **Business** (5,990₽/мес)
   - Всё включено + VIP поддержка
   - Кастомизация
   - Выделенный менеджер
   - SLA гарантии
