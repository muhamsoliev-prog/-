# OSINOT

Платформа автоматизации продаж на маркетплейсах с AI-бидером.

## 🚀 Установка

1. Убедитесь, что у вас установлены:
   - **Node.js** (версия 16+)
   - **MongoDB** (локально или облачная: MongoDB Atlas)
   - **Git** (опционально, для клонирования)

2. Скачайте проект:
   ```bash
   git clone https://github.com/osinot/osinot.git
