# Скилл «Строительство и ремонт»

Профессиональная база знаний для Claude: этапы и материалы (от фундамента и бетона до обоев и интерьера),
формулы расхода, сметы и КП, нормы СП/ГОСТ, фасады, 3D и визуализация.

- `SKILL.md`: точка входа и правила работы
- `references/`: справочники по темам
- `scripts/calc.py`: калькулятор расхода материалов (`python3 scripts/calc.py --help`)
- `templates/prices.csv`: прайс работ и материалов, **заполнить своими ценами** (Москва и МО)

Скилл подхватывается автоматически в любой сессии Claude Code в этом репозитории.
