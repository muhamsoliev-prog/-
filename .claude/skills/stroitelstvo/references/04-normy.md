## Теплотехника: Москва
- Требуемое сопротивление теплопередаче (ориентир): стены ≈ 3,1–3,2; покрытие/кровля ≈ 4,6–4,7;
  перекрытие над холодным подвалом ≈ 4,1 м²·°C/Вт. Точные значения считаются по ГСОП (СП 50.13330, СП 131.13330).
- λ (Вт/м·°C, условия эксплуатации Б, ориентир): газобетон D400 ≈ 0,113–0,117, D500 ≈ 0,14; кирпич
  полнотелый ≈ 0,7–0,8; керамоблок ≈ 0,14–0,18 (на тёплом растворе); минвата ≈ 0,036–0,042;
  ЭППС ≈ 0,030–0,034; пенополистирол ППС ≈ 0,038–0,041.
- R слоя = толщина (м) / λ. R конструкции = ∑R слоёв + 1/8,7 + 1/23.

## Допуски при приёмке отделки (СП 71.13330, ориентиры)
| Поверхность | Отклонение по 2-метровой рейке |
|---|---|
| Штукатурка «улучшенная» | ≤ 3 мм (до 2 неровностей) |
| Штукатурка «высококачественная» | ≤ 2 мм |
| Шпаклёвка под покраску (высокое качество) | ≤ 1–2 мм |
| Стяжка под ламинат/паркет | ≤ 2 мм на 2 м |
| Плитка: перепад между соседними плитками | ≤ 1 мм (керамика) |
Используй эти цифры при приёмке у бригады и в договоре с клиентом.

## Когда нужен специалист (обязательно предупреждай)
- Перепланировка с несущими стенами, проёмы в несущих стенах, перекрытия → проект и согласование.
- Газ → только газовая служба/лицензированная организация.
- Фундамент на торфе, плывунах, склонах → геология + расчёт конструктора.
- Подключение к сетям ≥ 15 кВт, вводной щит → электрик с допуском.
