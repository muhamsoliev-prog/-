# 3D, визуализация и цифровые продукты для стройки

## Честно про «лучше, чем AutoCAD»
AutoCAD/Revit/ArchiCAD — инструменты инженера для рабочих чертежей. Сайт их не заменит и не должен.
Наше преимущество там, где они слабы: **для клиента**. Клиент без навыков за 2 минуты видит свой дом в 3D,
меняет фасад/кровлю/отделку и сразу получает смету и заявку. AutoCAD такого не умеет, и это продаёт.

## Что строим на сайте (по приоритету ценности)
1. **Калькулятор сметы** (фасад/ремонт/фундамент): размеры → материалы → 3 варианта цены → заявка.
   Логика расчёта берётся из `scripts/calc.py` (портировать в JS/TS один в один).
2. **3D-конфигуратор дома**: параметрическая коробка (длина, ширина, этажность, тип кровли, окна) + переключение
   материалов фасада (штукатурка, клинкер, керамогранит, дерево) → цена пересчитывается.
3. **«Ваш дом с новым фасадом»**: клиент загружает фото дома → AI-рендер 2–3 вариантов фасада → заявка.
4. **Галерея объектов** до/после + 3D-туры.
5. **Каталог материалов** с карточками (пригодится и для маркетплейсов/Авито).

## 3D в браузере (Three.js)
- Для быстрого показа в чате есть **Three.js 3D Viewer** (MCP `show_threejs_scene`); на сайте используется `three` или `@react-three/fiber` + `@react-three/drei`.
- Параметрический дом строится из примитивов: `BoxGeometry` (стены, плита), `ExtrudeGeometry` (фронтоны, кровля),
  вычитание проёмов через отдельные меши окон или CSG (`three-bvh-csg`).
- Материалы: `MeshStandardMaterial` с PBR-текстурами (albedo/normal/roughness), например бесплатные текстуры
  ambientCG/Poly Haven (CC0): штукатурка, кирпич, бетон, дерево, металл кровли.
- Освещение: `HemisphereLight` + `DirectionalLight` с тенями, HDRI-окружение (`Environment` из drei) для реализма.
- Производительность: текстуры 1–2K, KTX2/Basis сжатие, `glTF/GLB` для готовых моделей (Draco), lazy-load сцены.
- Импорт из CAD: модели из ArchiCAD/Revit/SketchUp → экспорт в glTF/GLB/OBJ/FBX → в сайт.

## Фотореалистичные рендеры (AI)
Промпт-шаблон для фасада:
`Photorealistic exterior of a two-storey private house near Moscow, [материал фасада: light beige silicone plaster
with dark clinker brick plinth], [кровля: graphite metal standing-seam roof], large panoramic windows with dark
frames, [окружение: birch trees, lawn, paving stones], soft overcast daylight, architectural photography, 35mm, high detail`

Промпт-шаблон для интерьера:
`Photorealistic interior of a [living room], [стиль: japandi], [материалы: light oak engineered flooring,
warm white matte walls, linen sofa], hidden LED cove lighting 3000K, large window, natural daylight,
interior design magazine photo, wide angle 24mm`
- Генерировать 3 варианта и показывать клиенту выбор.
- Помечать на сайте: «визуализация, итоговый вид может отличаться».

## Фото и карточки стройматериалов (маркетплейсы, Авито, каталог)
1. Удаление фона → белый фон (#FFFFFF), товар занимает 80–90% кадра.
2. Единый ракурс и свет для всей категории.
3. Инфографика на 2–5 слайдах: размеры, расход на м², применение, сравнение с аналогом, «в интерьере».
4. Обязательные характеристики: марка/класс, размеры, вес, расход, морозостойкость (для фасадных и наружных), ГОСТ/ТУ, страна.
5. 3D-модель или 360°-вращение повышает конверсию (где площадка поддерживает).
