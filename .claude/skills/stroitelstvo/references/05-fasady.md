# Фасады (основной профиль бизнеса)

## Сравнение систем
| Система | Пирог (изнутри → наружу) | Срок службы | Плюсы | Минусы |
|---|---|---|---|---|
| **Мокрый фасад (СФТК)** | Стена → клей → утеплитель (минвата/ППС) + дюбели → базовый армированный слой (клей + сетка 145–165 г/м²) → грунт → декоративная штукатурка → фасадная краска | 25–30+ лет | Цена, бесшовность, любой цвет | Только при +5…+30 °C, сухая погода; требует строгой технологии |
| **Вентфасад (НВФ)** | Стена → утеплитель + ветрозащита → вентзазор 40–60 мм → подсистема (оцинковка/алюминий) → облицовка (керамогранит, фиброцемент, композит, сайдинг) | 40–50 лет | Монтаж круглый год, ремонтопригодность | Дороже, нужен расчёт подсистемы |
| **Клинкерная плитка** | Стена → утеплитель → армированный слой → клей → клинкер → затирка | 50+ лет | Премиальный вид кирпича | Дорого, трудоёмко |
| **Термопанели** (утеплитель + клинкер) | Стена → панели на дюбелях + запенивание стыков | 30+ лет | Быстро, всепогодно | Цена материала |
| **Облицовочный кирпич** | Стена → утеплитель → вентзазор → кирпич на гибких связях | 100 лет | Долговечность | Нужен фундамент под облицовку |
| **Штукатурка без утепления** | Стена → цементная штукатурка → декор | 15–25 лет | Дёшево | Только для тёплых стен (газобетон 400+) |

## Мокрый фасад: технология (контрольные точки)
1. **Основание**: прочность, чистота, ровность ≤ 1 см/м (иначе выравнивание). Грунт.
2. **Цокольный профиль** на высоте ≥ 300 мм от земли; ниже ЭППС.
3. **Утеплитель**: минвата фасадная плотностью ≥ 135–150 кг/м³ (НГ, негорючая) или ППС-16Ф/ППС-25Ф.
   Клей полосой по периметру + маяки (≥ 40% площади, для минваты сплошное нанесение гребёнкой).
   Плиты кладутся вразбежку, без крестовых стыков; на углах проёмов плиты цельные, Г-образные (без стыка по углу проёма).
4. **Противопожарные рассечки** из минваты над проёмами и по этажам при ППС (обязательны по нормам).
5. **Дюбелирование** через 1–3 суток: 6–8 шт/м², краевые зоны больше; тарелка в одной плоскости с утеплителем.
6. **Армирование**: угловые профили с сеткой, диагональные «косынки» 200×300 мм на углах проёмов,
   сетка внахлёст 100 мм, утоплена в верхнюю треть слоя 3–5 мм.
7. **Декоративная штукатурка**: минеральная (дёшево, под покраску), акриловая, силиконовая (оптимум: грязеотталкивание, паропроницаемость), силикатная.
   Наносить захватками без перерывов в пределах одной плоскости, без прямого солнца и дождя.
8. **Окраска** силиконовой фасадной краской в 2 слоя (для минеральной обязательно).

**Частые ошибки → брак**: работы при t < +5 °C, отсутствие косынок → трещины от углов проёмов;
стыки плит над углами проёмов; дюбели «утоплены» или торчат → пятна на фасаде; разнотон из-за перерыва внутри плоскости.

## Расход на 1 м² мокрого фасада (ориентир)
| Материал | Расход |
|---|---|
| Клей для приклеивания утеплителя | 4–6 кг |
| Утеплитель | 1,05 м² (запас 5%) |
| Дюбели тарельчатые | 6–8 шт (минвата), 4–6 шт (ППС) |
| Базовый армирующий клей | 4–6 кг (слой 3–5 мм) |
| Стеклосетка | 1,15 м² |
| Грунт под декоративную штукатурку | 0,2–0,3 кг |
| Декоративная штукатурка «короед»/«шуба» 1,5–2 мм | 2,5–3,5 кг |
| Фасадная краска (2 слоя) | 0,3–0,4 л |
| Угловой профиль с сеткой | по периметру углов и откосов |

## Вентфасад: ключевые параметры
- Подсистема по расчёту на ветровую нагрузку (высота, район); кронштейны с паронитовыми прокладками (терморазрыв).
- Утеплитель двухслойный или однослойный с ветрогидрозащитной мембраной; 2 дюбеля на плиту минимум.
- Вентзазор 40–60 мм, открытый снизу и сверху (просечки/перфорированные планки).
- Облицовка: керамогранит 600×600 на кляммерах (видимых/скрытых), фиброцементные панели (Cembrit, Equitone, отечественные аналоги), HPL, композит (только сертифицированный по горючести для высоты).

## Как продавать фасад (для сайта и КП)
- Показать **3D-визуализацию дома клиента** с 2–3 вариантами фасада (по фото дома, AI-рендер) — главный триггер продаж.
- Посчитать **экономию на отоплении** от утепления (теплопотери ↓, окупаемость в годах).
- Гарантия на работы письменно + фотоотчёт скрытых работ (утепление, армирование, дюбели) — снимает страх «сделают плохо».
