# 🎯 OSINOT v1.0.0 - Система управления E-commerce

Полнофункциональное веб-приложение для управления продажами на электронных маркетплейсах с поддержкой 4 языков, аналитикой и интеграцией с Wildberries API.

**Статус:** ✅ Production Ready | **Версия:** 1.0.0 | **Лицензия:** MIT

---

## 📊 Ключевые возможности

### 📈 Дашборд
- 8 KPI карточек с трендами (выручка, прибыль, налоги и т.д.)
- 7-дневный график продаж с 3 сериями данных
- Таблица регионов с распределением продаж
- Цветовое кодирование и анимации

### 📦 Управление товарами
- Каталог с поиском и сортировкой по любому столбцу
- Информация о запасах, цене, продажах, рейтинге
- Статус низких остатков (красное выделение)

### 💰 Финансовая аналитика
- Анализ себестоимости и маржи по категориям
- История удержаний и комиссий маркетплейса
- Графики выплат и банковские реквизиты
- Расчёты прибыли и ROI

### ⚙️ Настройки и интеграция
- Профиль пользователя с редактированием
- **4 языка интерфейса:** Русский 🇷🇺, English 🇺🇸, 中文 🇨🇳, Тоҷикӣ 🇹🇯
- API токены (Wildberries, OZON, Яндекс.Маркет)
- Уведомления (Email, Telegram, низкие остатки)

### 🌐 Локализация
- Полная поддержка 4 языков
- Автоматическое форматирование чисел, дат, валют по локали
- Сохранение выбора языка в localStorage
- Мгновенное переключение без перезагрузки

## 📡 API интеграция - Wildberries

OSINOT интегрируется с 4 типами Wildberries API:

### 🛒 Marketplace API
- Управление товарами и заказами
- Работа с логистикой
- Управление ценами и акциями

### 📊 Statistics API
- Статистика продаж
- Аналитика товаров
- Данные о возвратах

### 📝 Content API
- Редактирование карточек товаров
- Загрузка изображений
- SEO оптимизация

### 👤 Seller API
- Информация о продавце
- Баланс и выплаты
- Документы и договоры

### Получение токенов
1. https://seller.wildberries.ru
2. Настройки → Интеграция → API Ключи
3. Создайте ключи для каждого типа
4. Добавьте в Settings → API Tokens

VITE_WB_CONTENT_TOKEN=your_token_here
VITE_WB_SELLER_TOKEN=your_token_here
