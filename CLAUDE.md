# Claude Code — правила проекта

## Экономия токенов

### Context7 — использовать ТОЛЬКО когда нужно

**Вызывай Context7** (`mcp__context7__*`) только для:
- API который мог измениться после 2024 года (breaking changes)
- Точный синтаксис конфигурационных файлов конкретной версии
- Гайды по миграции между версиями (Next.js 14→15, Prisma 5→6 и т.д.)
- Установка и настройка CLI инструментов

**НЕ вызывай Context7** для:
- Общих концепций TypeScript (типы, дженерики, утилиты)
- Базовых React hooks (useState, useEffect, useCallback)
- Стандартных паттернов (async/await, Promise.all, Array.map)
- Отладки бизнес-логики
- Рефакторинга кода
- Написания скриптов с нуля

**Правило перед каждым вызовом Context7:**
> Могу ли я ответить на этот вопрос из обучающих данных?
> Если да — не вызывай Context7.

---

### Общие правила экономии токенов

- **Читай только нужные части файлов** — используй `offset` и `limit` в Read
- **Grep перед Read** — сначала найди строку через Grep, потом читай контекст
- **Один инструмент = один вопрос** — не читай весь файл чтобы найти одну функцию
- **Не повторяй** — если факт уже установлен в разговоре, не перепроверяй его
- **Параллельные вызовы** — независимые операции запускай одновременно

## Стек проекта (справочник — не нужен Context7)

- **Next.js 14** App Router, TypeScript, Tailwind CSS, shadcn/ui
- **Prisma ORM** + PostgreSQL, BigInt dirams (1 TJS = 100 dirams)
- **BullMQ** + Redis для очередей
- **Meilisearch 1.x** для поиска (RU + TG)
- **Anthropic SDK** (`@anthropic-ai/sdk`) — только этот, не OpenAI
- **Vitest** для тестов, **Playwright** для E2E

## Правила кода

- Деньги всегда `BigInt` dirams в Prisma — никогда `number` или `Decimal`
- Двуязычность обязательна: `titleRu` + `titleTg` везде
- COD (наличные при получении) = 60% заказов — всё должно работать с COD
- Минимальная зона касания 44×44px (Android mobile-first)
- `trackAIUsage(model, feature, inputTokens, outputTokens)` после каждого Anthropic вызова
